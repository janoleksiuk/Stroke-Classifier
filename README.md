# Stroke Binary Classifier - ML Project

This is a small machine learning project implementing a binary classifier to predict stroke risk. The models used include:

- Support Vector Machine (SVM) with Radial Basis Function (RBF) kernel
- K-Nearest Neighbors (KNN)

## Objective
